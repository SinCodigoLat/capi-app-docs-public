# CAPI App - Manual de Usuario

Bienvenido al **Manual de Usuario de CAPI App**, una plataforma médica integral que permite a clínicas y profesionales de la salud gestionar historiales clínicos, consultas, citas y comunicarse con pacientes de manera eficiente y segura.

## 📋 Sobre CAPI

**CAPI** (Centro de Atención Integral) es una aplicación móvil y web que cumple con normativas COFEPRIS para la gestión de historiales clínicos electrónicos, notas médicas, consentimientos informados y auditoría de datos médicos.

### Características Principales

- 🏥 **Gestión de Historial Clínico** - Expediente clínico electrónico completo
- 👥 **Gestión de Usuarios** - Doctores, pacientes y asistentes con roles granulares
- 📅 **Sistema de Citas** - Agendamiento y calendario integrado
- 💬 **Comunicación** - Chat en tiempo real y notificaciones push
- 🎥 **Videoconsultas** - Integración con Zoom
- 💳 **Pagos y Suscripciones** - Stripe y RevenueCat
- 🤖 **Inteligencia Artificial** - Sistema de créditos AI
- 🔐 **Cumplimiento normativo** - Operamos bajo el marco COFEPRIS (NOM-024, NOM-004) y LFPDPPP
- 📡 **Disponibilidad 24/7** - Monitoreo continuo y status page pública
